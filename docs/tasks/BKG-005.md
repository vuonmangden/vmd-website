# BKG-005 — Booking State Machine (Sandbox)

- **Task ID:** `BKG-005`; **Status:** In progress (`SYNTHETIC_ONLY`)
- **Dependencies:** `BKG-004`, `MNT-014`
- **Scope:** Server-side state transition validation and immutable `booking_status_history`. Cancellation/expiry releases active hold and occupancy in the same database transaction.
- **Excluded:** payment-driven transitions, refund policy, public API and real booking operations.
- **Invariant:** no direct status mutation outside service; every transition records history; invalid transitions fail closed.
