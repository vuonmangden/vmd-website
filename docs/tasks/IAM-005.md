# IAM-005 — Security Middleware

## 1. Thông tin task

- **Task ID:** `IAM-005`
- **Tên task:** Security Middleware
- **Trạng thái:** In progress
- **Branch:** `feat/iam-005-security-middleware`
- **Dependency:** FND-004, IAM-001

## 2. Mục tiêu

Bật secure headers, CORS allowlist và giới hạn kích thước request theo Tech Spec §35.1 và Security Baseline §7.

## 3. Phạm vi

### Trong phạm vi

- Helmet với CSP, HSTS, Referrer-Policy, frameguard, noSniff.
- CORS allowlist đọc từ `CORS_ALLOWED_ORIGINS`; không dùng `*` khi có credential.
- Body size limit 1mb.
- Unit tests cho config.

### Ngoài phạm vi

- Rate limiting (đã có ThrottleModule).
- CSRF (Phase 1 dùng Bearer token, không dùng cookie auth — §35.1 chỉ yêu cầu CSRF khi dùng cookie).
- CAPTCHA (§35.3, task riêng).

## 4. Dependency mới

`helmet@8.1.0` — thư viện chuẩn cho secure headers trong Express/NestJS. Security Baseline §7 yêu cầu CSP, `X-Content-Type-Options`, `Referrer-Policy`, frame protection; helmet cung cấp toàn bộ với cấu hình khai báo.

## 5. Environment variables

- `CORS_ALLOWED_ORIGINS` — danh sách origin, phân tách bằng dấu phẩy. Trống nghĩa là từ chối tất cả (deny-by-default).

## 6. Definition of Done

- Secure headers áp dụng cho mọi response.
- CORS chỉ chấp nhận origin trong allowlist; mặc định từ chối.
- Body size limit áp dụng.
- Quality gates pass.
