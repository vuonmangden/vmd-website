# RMS-006 — Availability Search (Sandbox)

- **Task ID:** `RMS-006`; **Status:** In progress (`SYNTHETIC_ONLY`)
- **Dependencies:** `RMS-002`, `RMS-004`, `MNT-014`
- **Scope:** Server-side availability by room type/date/guest count using active physical rooms and non-cancelled room blocks only.
- **Excluded:** occupancy, holds, bookings, public route, payment; these belong to Booking Core. No real inventory or production claims.
- **Rules:** interval is `[checkIn, checkOut)`; only `ACTIVE` rooms from non-archived room types; exclude rooms with overlapping un-cancelled blocks; validate date and guest count.
- **Done:** database integration tests for active/blocked/cancelled/inactive and date overlap; full gates/hosted CI.
