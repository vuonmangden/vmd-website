## 2. Bối cảnh

Execution Plan (mục 5) yêu cầu API foundation gồm error format, correlation ID, structured logger, validation pipe, global exception filter, Swagger/OpenAPI và health endpoints. Đây là nền tảng cho mọi module nghiệp vụ trong `apps/api` và `apps/worker`. Task này chỉ thiết lập cơ sở hạ tầng API; không triển khai module nghiệp vụ, database schema, authentication hoặc provider thật.
