# BKG-004 — Booking Creation (Sandbox)

- **Task ID:** `BKG-004`; **Status:** In progress (`SYNTHETIC_ONLY`)
- **Dependencies:** `BKG-001`, `BKG-003`, `RMS-005`, `MNT-014`
- **Scope:** Internal sandbox creation of a minimal pending-payment room booking. It creates booking, booking-room price snapshot, occupancy, resource hold, idempotency record and outbox event in one database transaction.
- **Forbidden:** public booking, deposit/payment amount, SePay, notification delivery, cancellation/refund policy and real operating data.
- **Invariant:** `Idempotency-Key` required; any occupancy unique collision returns `BOOKING_CONFLICT`; monetary snapshot is immutable integer VND.
