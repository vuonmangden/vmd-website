# MNT-003 — Delivery Readiness Matrix and Synthetic Fixture Handoff

## 1. Thông tin task

- **Task ID:** `MNT-003`
- **Trạng thái:** Done
- **Dependency:** `MNT-002`, `FND-003`, `FND-005`, `BKG-001`, `NTF-001`
- **Phê duyệt:** Chủ dự án yêu cầu thực hiện theo lộ trình tăng tốc ngày 2026-08-09.
- **Mục tiêu:** Biến dependency/PRE/file ownership/migration/database verification thành gate thực thi rõ ràng và tạo task độc lập cho synthetic fixtures.

## 2. Phạm vi

- Tạo `docs/10_DELIVERY_READINESS_MATRIX.md`.
- Phân biệt rõ `Blocked`, `Planning only` và `Implementation approved` mà không thay đổi trạng thái chuẩn trong tracker.
- Xác định branch/worktree owner, file scope, migration owner, database verification, merge order và rollback gate cho các lane kế tiếp.
- Tạo task `TST-001` cho synthetic fixtures có production fail-closed.
- Cập nhật progress tracker và liên kết evidence.

## 3. Ngoài phạm vi

- Không triển khai fixture/seed trong task này.
- Không mở IAM-001, CMS-005 hoặc NTF-002 khi PRE bắt buộc còn `Blocked`.
- Không thay dữ liệu giả lập bằng dữ liệu production hoặc đánh dấu PRE là đã duyệt.
- Không thêm dependency, migration hoặc thay đổi API.

## 4. Acceptance criteria

- Mỗi candidate task có dependency evidence và implementation permission.
- Không có hai lane cùng sở hữu file/module, migration sequence hoặc database verification.
- `TST-001` có scope, guard, test, security và Definition of Done rõ ràng.
- Matrix chỉ ra chính xác task nào được phép bắt đầu tiếp theo.
- `git diff --check` đạt; thay đổi chỉ gồm tài liệu.

## 5. Security

- Synthetic data không chứa PII, tài khoản, provider identifier hoặc secret thật.
- Planning không được dùng để vượt qua server-side authorization, PRE hoặc production readiness gate.
- Tất cả thao tác destructive/production vẫn cần chủ dự án phê duyệt.

## 6. Definition of Done

- Readiness matrix và TST-001 task spec được review.
- Tracker phản ánh đúng task hiện tại và task tiếp theo đủ điều kiện.
- Branch có CI xanh và Pull Request được merge qua branch protection.
