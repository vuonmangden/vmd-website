# BKG-003 — Resource Holds (Sandbox)

- **Task ID:** `BKG-003`; **Status:** In progress (`SYNTHETIC_ONLY`)
- **Dependencies:** `BKG-002`, `MNT-014`
- **Scope:** Generic resource hold with expiry, idempotency and release lifecycle. Default hold duration is config `BOOKING_HOLD_MINUTES` (Tech Spec §16.2: 15); no hard-coded production policy.
- **Rules:** `ACTIVE`, `CONFIRMED`, `RELEASED`, `EXPIRED`; one idempotency key maps to one hold; expiry cleanup releases occupancy in the same transaction when BKG-004 links the booking lifecycle.
- **Excluded:** customer/order/booking/payment and public booking endpoint.
