## 2. Bối cảnh

Execution Plan (mục 5) yêu cầu database foundation gồm Prisma ORM setup, migration đầu tiên với bốn bảng nền tảng (`audit_logs`, `idempotency_keys`, `outbox_events`, `app_settings`), kết nối database từ NestJS và health check database. Đây là nền tảng cho mọi module nghiệp vụ cần truy cập dữ liệu. Task này chỉ thiết lập cơ sở hạ tầng database; không triển khai schema nghiệp vụ phòng, booking, BBQ, payment, notification hoặc bất kỳ module nào ngoài foundation.

- Thiết lập Prisma ORM 7.x kết nối PostgreSQL 16 từ Docker Compose (FND-002).

- Cung cấp seed script tối thiểu để xác minh migration hoạt động.

## 6. User story

**Là** đội phát triển Vườn Măng Đen, **tôi muốn** có database foundation với schema nền tảng và Prisma ORM đã kết nối, **để** các module nghiệp vụ Phase 1 có thể mở rộng schema bằng migration mà không phải thiết lập lại cơ sở hạ tầng database.

Luồng chính:

1. Chạy Docker Compose để khởi động PostgreSQL (đã có từ FND-002).
2. Chạy `prisma migrate dev` để tạo database schema từ migration.
3. Chạy seed script để xác minh bảng hoạt động.
4. Khởi động API và xác nhận `/health/dependencies` trả database healthy.

Luồng lỗi:

- PostgreSQL chưa chạy: health check trả `unhealthy` với thông tin rõ ràng.
- Migration thất bại: báo lỗi cụ thể, không tự retry.
- Biến `DATABASE_URL` thiếu: API khởi động thất bại với message rõ ràng, không in connection string.

## 7. Quy tắc kỹ thuật bắt buộc

1. PostgreSQL là nguồn dữ liệu chuẩn; mọi thay đổi schema qua Prisma migration.
2. ID sử dụng UUID; `pgcrypto` extension cho `gen_random_uuid()`.
3. Timestamp lưu UTC dạng `TIMESTAMPTZ`; ngày vận hành (stay date) dùng `DATE`.
4. Tiền lưu bằng số nguyên VND; không dùng float; financial tables có cột `currency` default `VND`.
5. Column naming: `snake_case` trong database; Prisma maps sang `camelCase` trong TypeScript.
6. Mọi business table có `created_at`, `updated_at`. Soft-delete dùng `deleted_at`. Financial data không soft delete.
7. Enums stored as controlled strings (varchar), không dùng PostgreSQL native enum.
8. `audit_logs` là immutable; không có `UPDATE` hoặc `DELETE` logic.
9. `idempotency_keys` có TTL; same key + different request hash trả 409.
10. `outbox_events` ghi trong cùng transaction với business change (transactional outbox).
11. `app_settings` không lưu secret trực tiếp; chỉ reference.
12. Không dùng `db push` cho production; chỉ dùng `prisma migrate deploy`.
13. Không sửa migration đã chạy.
14. `DATABASE_URL` chỉ ở server-side; không bao giờ vào frontend.

## 10. Schema bốn bảng nền tảng

### 10.1. `audit_logs`

| Column | Type | Constraint | Ghi chú |
|---|---|---|---|
| `id` | `UUID` | PK, default `gen_random_uuid()` | |
| `actor_type` | `VARCHAR(30)` | NOT NULL | `system`, `staff`, `customer` |
| `actor_id` | `UUID` | NULL | NULL khi actor_type = system |
| `action` | `VARCHAR(100)` | NOT NULL | Ví dụ: `booking.create`, `payment.confirm` |
| `resource_type` | `VARCHAR(100)` | NOT NULL | |
| `resource_id` | `UUID` | NOT NULL | |
| `before_data` | `JSONB` | NULL | Snapshot trước thay đổi |
| `after_data` | `JSONB` | NULL | Snapshot sau thay đổi |
| `reason` | `TEXT` | NULL | Lý do thay đổi |
| `ip_address` | `INET` | NULL | |
| `user_agent` | `TEXT` | NULL | |
| `correlation_id` | `UUID` | NULL | Từ FND-004 correlation ID |
| `created_at` | `TIMESTAMPTZ` | NOT NULL, default `now()` | |

**Index:** `(resource_type, resource_id, created_at)`.

**Constraint:** Immutable — không có UPDATE hoặc DELETE trong application logic.

### 10.2. `idempotency_keys`

| Column | Type | Constraint | Ghi chú |
|---|---|---|---|
| `key` | `VARCHAR(180)` | PK | |
| `scope` | `VARCHAR(80)` | NOT NULL | `booking`, `payment`, `refund` |
| `request_hash` | `VARCHAR(128)` | NOT NULL | SHA-256 của request body |
| `response_status` | `INTEGER` | NULL | Cached HTTP status |
| `response_body` | `JSONB` | NULL | Cached response |
| `expires_at` | `TIMESTAMPTZ` | NOT NULL | TTL theo scope |
| `created_at` | `TIMESTAMPTZ` | NOT NULL, default `now()` | |

**TTL mặc định:** booking 24h, payment 7d, refund 30d.

**Logic:** Same key + same request_hash → trả cached response. Same key + different request_hash → 409 Conflict.

### 10.3. `outbox_events`

| Column | Type | Constraint | Ghi chú |
|---|---|---|---|
| `id` | `UUID` | PK, default `gen_random_uuid()` | |
| `aggregate_type` | `VARCHAR(80)` | NOT NULL | Ví dụ: `booking`, `payment` |
| `aggregate_id` | `UUID` | NOT NULL | |
| `event_type` | `VARCHAR(100)` | NOT NULL | Ví dụ: `booking.created` |
| `payload` | `JSONB` | NOT NULL | |
| `status` | `VARCHAR(30)` | NOT NULL, default `pending` | `pending`, `published`, `failed` |
| `attempt_count` | `INTEGER` | NOT NULL, default `0` | |
| `created_at` | `TIMESTAMPTZ` | NOT NULL, default `now()` | |
| `published_at` | `TIMESTAMPTZ` | NULL | |

**Index:** `(status, created_at)` cho worker polling.

**Pattern:** Event ghi trong cùng transaction với business change.

### 10.4. `app_settings`

| Column | Type | Constraint | Ghi chú |
|---|---|---|---|
| `key` | `VARCHAR(150)` | PK | |
| `value` | `JSONB` | NOT NULL | |
| `category` | `VARCHAR(80)` | NOT NULL | `general`, `booking`, `payment`, `notification` |
| `is_secret_reference` | `BOOLEAN` | NOT NULL, default `false` | `true` = value chỉ chứa reference, không phải secret thật |
| `updated_by` | `UUID` | NULL | |
| `updated_at` | `TIMESTAMPTZ` | NOT NULL, default `now()` | |

**Constraint:** Khi `is_secret_reference = true`, `value` chỉ chứa tên biến môi trường hoặc vault path, không phải secret thật.

## 11. PostgreSQL Extensions

Migration đầu tiên phải bật:

- `pgcrypto` — cho `gen_random_uuid()`.
- `btree_gist` — cho exclusion constraints (phục vụ booking/occupancy sau).
- `citext` — cho case-insensitive text (phục vụ email/username sau).

## 12. PrismaService và PrismaModule

### PrismaService

- Extends `PrismaClient`.
- Implements `OnModuleInit` và `OnModuleDestroy`.
- `onModuleInit()`: gọi `$connect()`.
- `onModuleDestroy()`: gọi `$disconnect()`.
- Không log connection string hoặc credential.

### PrismaModule

- `@Global()` module export `PrismaService`.
- Registered một lần trong `AppModule`.

## 13. Health check database

Cập nhật `HealthController.dependencies()`:

- Thực hiện `SELECT 1` qua PrismaService.
- Trả `database: "healthy"` hoặc `database: "unhealthy"` với lý do.
- Không trả connection string hoặc credential trong response.

## 14. Seed script

- File: `prisma/seed.ts`.
- Chèn một bản ghi `app_settings` smoke record: `key = 'app.name'`, `value = '"Vườn Măng Đen"'`, `category = 'general'`.
- Dùng upsert để idempotent khi chạy lại.
- Không chèn dữ liệu nghiệp vụ giả (phòng, giá, booking, khách hàng).
