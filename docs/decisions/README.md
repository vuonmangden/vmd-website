# Architecture Decision Records

Thư mục này lưu các quyết định kiến trúc hoặc kỹ thuật quan trọng phát sinh trong quá trình triển khai.

Mỗi quyết định tạo một file:

```text
ADR-001-short-title.md
ADR-002-short-title.md
```

Một ADR tối thiểu gồm: bối cảnh, vấn đề, các phương án, quyết định, lý do, hệ quả, rủi ro, ngày và người phê duyệt. Không dùng ADR để tự thay đổi PRD, chính sách kinh doanh hoặc quy tắc bắt buộc trong `AGENTS.md`.
